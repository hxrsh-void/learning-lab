# KAGE — The Five Seals

A playable temple-mystery layer over the Kage night-walk experience.
Find five seals hidden along the scroll, then speak the guardian's name.

Original `kage.html` and `secret-pathways-assets/` come from the fromiedc
project (ThreeUI KageLandingPage source, hash-verified there). `game.js` and
`game.css` are original and add the game layer; the original page content is
unchanged apart from the tab title.
